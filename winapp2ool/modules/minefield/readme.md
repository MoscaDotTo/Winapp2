# Minefield

**Minefield** is a hidden winapp2ool module where we try out experimental and unfinished features. It isn't on the main menu and isn't meant for general use.

To open Minefield, type `m` at the main winapp2ool menu.

### Current status

Minefield has no options right now. Anything that turns up here is unfinished, and may be broken, incomplete, or gone in the next release.
