# Minefield

**Minefield** is a hidden winapp2ool module used as a testing ground for experimental and in-progress features. It is not listed on the main menu and is not intended for general use.

To access Minefield, type `m` at the main winapp2ool menu.

### Current status

Minefield currently has no selectable options. Any features under development here are works in progress and may be broken, incomplete, or subject to removal at any time.
