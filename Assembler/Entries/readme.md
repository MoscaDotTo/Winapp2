# Winapp2.ini Build Artifacts

### What is this?

This folder holds the generated build artifacts that are merged into winapp2.ini. **Every file here is machine-generated. Do not edit any of them directly.** Each file carries a header identifying the tool that generated it and the source files from which it was generated; changes made here are overwritten by every build.

| Artifact | Generated by | From |
| :- | :- | :- |
| `#.ini`, `A.ini` … `Z.ini` | [EntryBuilder](https://github.com/MoscaDotTo/Winapp2/blob/master/winapp2ool/modules/entrybuilder/readme.md) | The base entry sources in [`Assembler/EntryBuilder/`](https://github.com/MoscaDotTo/Winapp2/tree/master/Assembler/EntryBuilder) |
| `Browsers/browsers.ini` | [BrowserBuilder](https://github.com/MoscaDotTo/Winapp2/blob/master/winapp2ool/modules/browserbuilder/readme.md) | The browser definitions in [`Assembler/BrowserBuilder/`](https://github.com/MoscaDotTo/Winapp2/tree/master/Assembler/BrowserBuilder) |
| `UWP/uwp.ini` | [UWPBuilder](https://github.com/MoscaDotTo/Winapp2/blob/master/winapp2ool/modules/uwpbuilder/readme.md) | The app definitions in [`Assembler/UWP/AppInfo/`](https://github.com/MoscaDotTo/Winapp2/tree/master/Assembler/UWP/AppInfo) |

The base tier is split into 27 files alphabetically: each `<letter>.ini` contains every base entry whose name begins with that letter (numbers and symbols are in `#.ini`), bucketed by entry name. Entries here are normalized by WinappDebug during generation and may be incomplete on their own; they are inputs to the final merge, not a usable winapp2.ini.

### Why are generated files committed?

Auditability. Committing the artifacts makes every change to winapp2.ini reviewable at the entry level: a source or generator change shows up in the artifact diff of the same commit, reviewable by people other than the person who made it. The build script's `-Verify` mode regenerates all artifacts and byte-compares them against these committed files, failing on any mismatch so that the artifacts are guaranteed to match their sources at all times.

### How do I contribute?

Contributions target the source files, never this folder. See the [contributor guidelines](https://github.com/MoscaDotTo/Winapp2/blob/master/CONTRIBUTING.md) for how to write and submit an entry:

- **Standard (win32) application entries**: [`Assembler/EntryBuilder/<letter>.ini`](https://github.com/MoscaDotTo/Winapp2/tree/master/Assembler/EntryBuilder) standard winapp2.ini syntax is valid there as-is
- **Web browser entries**: [`Assembler/BrowserBuilder/`](https://github.com/MoscaDotTo/Winapp2/tree/master/Assembler/BrowserBuilder)
- **UWP (Microsoft Store) app entries**: [`Assembler/UWP/AppInfo/`](https://github.com/MoscaDotTo/Winapp2/tree/master/Assembler/UWP/AppInfo)
